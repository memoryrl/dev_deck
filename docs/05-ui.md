# 05. UI / Screen Design

시각 기준은 **shadcn/ui** (New York, CSS 변수)다. Next.js 14 + Tailwind 3과 맞추기 위해 Radix 기반 프리미티브를 `components/ui`에 둔다. CLI 기본값인 Tailwind 4 / `base-nova` 스타일은 쓰지 않는다.

컬러 시스템은 Coolors 5색을 토큰에 매핑한다. [팔레트](https://coolors.co/1a1614-6b4f3a-c4a574-e8dfd2-f6f1e9)

| 역할 | Hex | 토큰 |
| --- | --- | --- |
| Ink | `#1A1614` | `--foreground`, `--primary`, `--lux-espresso` |
| Umber | `#6B4F3A` | `--lux-cognac` (커리어 포인트) |
| Gold | `#C4A574` | `--ring`, `--lux-champagne` (프롬프트 포인트) |
| Stone | `#E8DFD2` | `--secondary`, `--lux-sand` |
| Parchment | `#F6F1E9` | `--background`, `--primary-foreground` |
| Field | `#FFFFFF` | `--field` (라이트 입력란·셀렉트·에디터 본문). 다크는 card에 가깝게 |

제목은 Public Sans, 본문은 Inter. 라이트 기본, 다크 토글. 히어로는 큰 헤드라인 + `Button` CTA + `Card` 그리드.

Envato/Fugu 원본 HTML/CSS는 저장소에 넣지 않는다.

미들웨어 가드: `/promptkit`, `/career`, `/steam` 및 하위. `/`, `/p`, `/work` 는 열어둠. `[id]`와 `skills`가 겹치지 않게 `skills` 정적 세그먼트를 동적보다 우선한다.

로그인 상태에서 `/login` 접근 시 Owner는 `/site/dashboard`, 회원은 `/account`로 보낸다.

회원가입 흐름: Google OAuth 콜백(`/auth/callback`)이 프로필을 upsert한 뒤 `terms_consents`를 본다. 두 문서(`terms`, `privacy`) 동의가 없으면 `/signup/terms`로 보내고, 동의를 저장하면 `/account`로 이어진다. `/account`도 같은 검사를 하므로 주소로 우회할 수 없다. Owner는 약관을 쓰는 쪽이라 게이트를 적용하지 않는다. 약관 테이블이 없으면(패치 미적용) 게이트를 건너뛰어 로그인을 막지 않는다.

에러 화면: `app/not-found.tsx`(404), `app/error.tsx`·`app/global-error.tsx`(500). 그 외 4xx·5xx 문구는 `lib/http-errors.ts`와 `/status/[code]`. 없는 글·비활성 게시판은 404, 게시판 보기 권한 부족은 비로그인 401·로그인 403.

## 2. 레이아웃

### 2.1 Root (`app/layout.tsx`)

- 폰트, `ThemeProvider` (**기본 `light`**, `dark` 클래스 토글), `Toaster`
- `next-themes` + 헤더 `ThemeToggle` (라이트 ↔ 다크). 시스템 테마를 기본값으로 쓰지 않는다.
- 언어는 `ko`/`en`. 공개 페이지는 푸터 로고 아래 스택(Next.js · Supabase · Steam API) 밑에 글로브 Language 스위처. 쿠키 `lang` + `?lang=` ([09-i18n.md](./09-i18n.md))
- 선택 값은 localStorage에 유지
- 글로벌 네비는 랜딩·`/p`·`/work` 헤더. `lg+`에서 우측 **AI Prompt / 커리어로그 / 게임리뷰** 클릭 시 메가메뉴. 좌측 패널은 랜덤 사진 + 어두운 오버레이로 문구 가독성 유지. 비로그인은 **로그인**, 로그인은 아바타·이름·권한 드롭다운(이메일, 로그아웃). **관리자(`owner`)**만 드롭다운에 PromptKit·CareerLog·Steam·게시판·메뉴. `lg` 미만은 우측 아바타 + 햄버거 → 우측 슬라이드 메뉴
- 공개 본문 폭은 헤더·푸터와 같다. `PublicContainer` → `max-w-6xl px-5`

## 3. 화면별 상태

모든 데이터 화면은 네 상태를 갖는다: **loading / empty / error / ready**.

### 3.1 Landing `/`

- 히어로: 한 줄 가치, CTA(커리어 보기 우선). 비로그인만 로그인 버튼. 메쉬 그라데이션, 우측 하단 상징 비주얼(덱 카드). 데스크톱에서 화살표·드래그로 같은 히어로 전체를 3D 토폴로지로 넘긴다. 카피는 고정.
- 숫자 스트립: 공개 프롬프트·커리어 글·보유 게임(누적 시간)·공개 리뷰 수
- 모듈 카드 PromptKit / CareerLog / Steam Tracker → 좌우 자동 스크롤(마퀴)
- 대표 작업 1건(공개 프로젝트 글 우선, 없으면 프롬프트) 후 좌우 최신 글 각 최대 4개. 대표작과 겹치면 목록에서 제외
- UMPC/Deck 한 카드(프리셋 또는 Deck 플레이) + 최근 활동(프롬프트·커리어·리뷰 날짜)
- Steam: 가운데 탭 — 최근 플레이 / 누적 시간 순위(1위 2행 + 우측 4장). 탭 아래 최신 리뷰. 제목 우측 더 보기
- 공개 스킬 상위 8개: 이름·숙련도·연차·한 줄. 없으면 섹션 숨김
- 최하단 CTA: 진한 코냑 카드 + 샴페인 그라데이션. 좌측 소개, 우측 GitHub·메일 버튼
- 푸터: Next.js · Supabase · Steam API, 연락처는 랜딩 CTA와 동일 소스. 카피라이트에 Created by nckim. 우측 **오픈소스 사용정보** → `/opensource`

### 3.1.1 공개 상세 `/p/[id]`

- 대시보드 셸 없음. 랜딩과 같은 공개 헤더
- 제목 우측 복사, 상단 예상 결과물, 하단 프롬프트는 기본 접힘·내용보기 토글
- 관리자면 상단 **편집** → 같은 화면에서 수정 폼. 저장 후 상세에 머무름
- 하단 댓글: 프롬프트·커리어·Steam은 비회원 작성. 공지·자유게시판은 회원 이상(`comment_role`). `RichEditor` / CKEditor 5, 무한 답글, 이름 옆 IP(마스킹)·지역. 욕설은 저장 시 치환
- 좌측 하단 `ArticleReader` 도크: 접힘 시 **본문 크기** 라벨만, 클릭하면 위로 가로 게이지(원본 100%가 가운데, 70–130%). **원래대로**로 초기화. 본문 제목·본문·코드는 `em` 비율로 함께 조절. 반투명 블러. localStorage
- 없거나 `is_public = false`이면 `notFound()`. 목록 6개 밖 공개 글도 URL이면 열림

### 3.1.2 공개 커리어 게시판 `/work`

- 공개 헤더. 제목: 커리어
- 상단 검색: 제목 조건 + 검색어 + 검색/초기화. `총 N건`
- 목록: `BulletinList` 표(번호·제목·작성자·등록일·분류). 번호는 최신이 큰 값. 카드형 아님
- 범용 게시판 글쓰기는 기본 숨김, **글쓰기** 토글로 아래로 펼침
- 정렬: `created_at DESC`. 한도 없음
- Empty: “아직 공개된 글이 없습니다”

### 3.1.3 공개 커리어 상세 `/work/[id]`

- 블로그 레이아웃. 제목, type, 회사/역할/기간, 스킬·태그, `RichContent` 본문
- `/p/[id]`와 같은 본문 크기 도크
- 관리자면 상단 **편집**으로 같은 화면에서 수정
- 없거나 비공개면 `notFound()`

### 3.1.4 범용 게시글 `/b/[slug]/[id]`

- 제목 + `RichContent` 본문. 본인 글이거나 관리자면 상단 **편집**으로 같은 화면에서 수정
- 공지사항 글쓰기는 관리자만, 자유게시판은 회원 이상. 댓글은 회원 이상
- `/p/[id]`와 같은 본문 크기 도크. 시스템 게시판 슬러그는 404

### 3.2 Login `/login`

- Google만
- 에러 쿼리(`?error=`) 시 Alert

### 3.2.1 약관 확인 `/signup/terms`

- 상단 단계 칩: 1 이용약관 → 2 개인정보처리방침 → 3 가입 완료
- 문서마다 카드: 제목·버전·수정일, 스크롤 본문(`RichContent`), 하단 "내용을 확인했습니다" 버튼. 누르면 "확인 완료"로 바뀌고 다시 누르면 취소
- 두 카드가 모두 확인 완료일 때만 "동의하고 가입 완료" 활성화. 저장 후 `/account`
- "동의하지 않음": 방금 만든 계정(30분 이내)이면 가입 취소 = 계정 삭제 + `member_events` 정리. 오래된 계정이면 로그아웃만
- 본문은 서버에서 sanitize 해 ReactNode로 내려준다 (클라이언트에 sanitize-html을 싣지 않기 위해)

### 3.2.2 약관 관리 `/site/terms` · `/site/terms/history`

- 탭(이용약관 / 개인정보처리방침)마다 **한국어 본문(필수)** 섹션과 **English 본문(선택)** 섹션 — 각각 제목 + CKEditor — 그리고 변경 메모. 저장하면 `terms_save()`로 버전 +1
- 영문은 제목·본문을 둘 다 채우거나 둘 다 비워야 한다(반쪽 번역 방지). 비우면 영어 화면(`/signup/terms`, `?lang=en`)은 한국어 본문에 "영문 번역이 아직 없어 한국어 원문을 표시합니다" 안내를 붙여 보여 준다
- 이력 목록: 문서·버전·제목(영문이 있으면 `EN` 배지)·변경 메모·수정자·수정일시, "현재" 배지, 보기 → 스냅샷 상세. 상세는 KO 본문과 EN 본문을 각각 카드로 보여 주고(영문 없으면 안내), 이전/다음 버전 이동

### 3.3 PromptKit 목록 `/promptkit`

**헤더:** 제목

**필터:** 제목 검색, 총 건수

### 3.5 CareerLog 목록 `/career`

**헤더:** 커리어, 스킬 관리(`/career/skills`)

**필터:** 제목 검색, 총 건수

**리스트:** `No. N | 제목`, 작성자(회사 또는 관리자), 등록일, 우측 type·공개 여부

**Empty:** “참여했던 프로젝트를 글로 남겨 보세요”

**생성/수정 필드:** title, post_type(세그먼트 또는 select), excerpt, content(`RichEditor`), company, role, period_start, period_end(비우면 진행 중), skills(콤마), tags(콤마), is_public

프로젝트 메타 필드는 `post_type = project`일 때 강조. 다른 타입이어도 입력은 허용한다.

### 3.8 Steam 목록 `/steam`

**헤더:** 프로필 아바타·이름, 게임 수, 누적/2주/Deck 시간, 마지막 플레이 게임

**정렬:** 누적 시간 (즐겨찾기 우선), 최근 플레이, 최근 2주

**카드:** header.jpg, name, 누적 시간, 마지막 플레이, 2주·Deck 배지, 리뷰 있음 점, 즐겨찾기 별

**Empty:** Steam 설정 안내 (프로필 공개, env)

**Error:** 프록시 메시지 그대로 보여 주되 시크릿 없음

공개 `/games`도 같은 `SteamLibrary`를 쓴다.

### 3.8.1 추천 게임 `/games/top`

헤더 **게임리뷰 > 추천 게임**은 `/#games` 해시가 아니라 `/games/top`으로 연다. 상단은 랜딩과 같은 로봇 토폴로지로 올림픽 시상식 구도: 은·금·동 계단, 금은동 메달을 목에 건 로봇 3명이 환호, 모니터에 Steam `header.jpg`, 우측 4–10등이 시상식을 바라보며 박수. 각 로봇에 순위 번호. 클릭 시 `/games/[appid]`. WebGL이 없어도 아래 순위 목록으로 이동 가능.

### 3.9 Steam 상세 `/steam/[appid]` · `/games/[appid]`

- 히어로(`library_hero` → header), 이름, Steam 상점 링크
- 누적/2주/마지막 플레이, 플랫폼·Deck 시간, Deck 호환, 업적 진행
- 상점 한 줄 소개, 장르, 개발/퍼블리셔, 출시일, Metacritic, 스크린샷(클릭 시 라이트박스 확대, 좌우 이동)

- 상점 API 실패 시에도 라이브러리·리뷰는 유지
