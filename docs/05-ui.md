# 05. UI / Screen Design

시각 기준은 **shadcn/ui** (New York, CSS 변수)다. Next.js 14 + Tailwind 3과 맞추기 위해 Radix 기반 프리미티브를 `components/ui`에 둔다. CLI 기본값인 Tailwind 4 / `base-nova` 스타일은 쓰지 않는다.

컬러 시스템은 Coolors 5색을 토큰에 매핑한다. [팔레트](https://coolors.co/1a1614-6b4f3a-c4a574-e8dfd2-f6f1e9)

| 역할 | Hex | 토큰 |
| --- | --- | --- |
| Ink | `#1A1614` | `--foreground`, `--primary`, `--lux-espresso` |
| Umber | `#6B4F3A` | `--lux-cognac` (커리어 포인트) |
| Gold | `#C4A574` | `--ring`, `--lux-champagne` (프롬프트 포인트) |
| Stone | `#E8DFD2` | `--secondary`, `--lux-sand` |
| Parchment | `#F6F1E9` | `--background`, `--primary-foreground` |

제목은 Public Sans, 본문은 Inter. 라이트 기본, 다크 토글. 히어로는 큰 헤드라인 + `Button` CTA + `Card` 그리드.

Envato/Fugu 원본 HTML/CSS는 저장소에 넣지 않는다.

## 1. 라우트 맵

| 경로 | 그룹 | 인증 | 목적 |
| --- | --- | --- | --- |
| `/` | root | 공개 | 랜딩 / 프롬프트·커리어 티저 각 4개, Steam 탭, 스킬 칩 |
| `/p/[id]` | root | 공개 | 공개 프롬프트 전문 |
| `/work` | root | 공개 | 커리어 게시판 (공개 글 전부) |
| `/work/[id]` | root | 공개 | 커리어 블로그 상세 |
| `/games` | root | 공개 | Steam 라이브러리 + 리뷰 (읽기) |
| `/games/[appid]` | root | 공개 | 게임 리뷰 상세 |
| `/b/[slug]` | root | 게시판 view_role | 범용 목록. 시스템 kind는 전용 공개 글 |
| `/b/[slug]/[id]` | root | 게시판 view_role | 범용 게시글 상세. 시스템은 404 |
| `/site/boards` | `(dashboard)` | Owner | 시스템+범용 게시판 목록 |
| `/site/boards/[id]` | `(dashboard)` | Owner | 설정. 범용은 글 CRUD, 시스템은 전용 대시보드 링크 |
| `/site/menus` | `(dashboard)` | Owner | 헤더/푸터 메뉴 CRUD |
| `/login` | `(auth)` | 비로그인 전용 | Google |
| `/account` | root | 로그인 회원 | 편집 없는 회원 안내. Owner는 `/promptkit` |
| `/promptkit` | `(dashboard)` | 필수 | 프롬프트 목록 + 생성 |
| `/promptkit/[id]` | `(dashboard)` | 필수 | Owner 프롬프트 수정 |
| `/career` | `(dashboard)` | 필수 | 커리어 글 게시판 + 생성 |
| `/career/skills` | `(dashboard)` | 필수 | 스킬 인벤토리 |
| `/career/[id]` | `(dashboard)` | 필수 | Owner 커리어 글 수정 |
| `/steam` | `(dashboard)` | 필수 | 게임 라이브러리 |
| `/steam/[appid]` | `(dashboard)` | 필수 | 게임 + 리뷰 폼 |

미들웨어 가드: `/promptkit`, `/career`, `/steam` 및 하위. `/`, `/p`, `/work` 는 열어둠. `[id]`와 `skills`가 겹치지 않게 `skills` 정적 세그먼트를 동적보다 우선한다.

로그인 상태에서 `/login` 접근 시 `/promptkit`으로 보낸다.

## 2. 레이아웃

### 2.1 Root (`app/layout.tsx`)

- 폰트, `ThemeProvider` (**기본 `light`**, `dark` 클래스 토글), `Toaster`
- `next-themes` + 헤더 `ThemeToggle` (라이트 ↔ 다크). 시스템 테마를 기본값으로 쓰지 않는다.
- 선택 값은 localStorage에 유지
- 글로벌 네비는 랜딩·`/p`·`/work` 헤더. `lg+`에서 우측 **AI Prompt / 커리어로그 / 게임리뷰** 클릭 시 메가메뉴, 로그인, 테마. 메가메뉴는 안내 칼럼과 링크 칼럼을 **한 패널**로 묶고, 하단 보더는 메뉴별 포인트색(Gold / Umber / Ink). `lg` 미만은 우측 상단 햄버거 → 우측 슬라이드 메뉴
- 공개 본문 폭은 헤더·푸터와 같다. `PublicContainer` → `max-w-6xl px-5`

### 2.2 Auth

- 중앙 카드. 로고 + Google OAuth 버튼
- 마케팅 카피는 한 줄

### 2.3 Dashboard (`(dashboard)/layout.tsx`)

```text
┌──────────┬─────────────────────────────┐
│ Sidebar  │ Top bar (테마, 유저 아바타, Logout) │
│          ├─────────────────────────────┤
│ PromptKit│                             │
│ CareerLog│         children            │
│ Steam    │                             │
│          │                             │
└──────────┴─────────────────────────────┘
```

Sidebar 항목:

| 라벨 | href | 아이콘 (Lucide) |
| --- | --- | --- |
| PromptKit | `/promptkit` | `Terminal` 또는 `Sparkles` |
| CareerLog | `/career` | `Briefcase` |
| Steam Tracker | `/steam` | `Gamepad2` |
| 게시판 | `/site/boards` | `LayoutList` |
| 메뉴 | `/site/menus` | `Menu` |

활성 라우트는 배경/폰트 weight로 구분. 모바일은 Sheet 사이드바.

## 3. 화면별 상태

모든 데이터 화면은 네 상태를 갖는다: **loading / empty / error / ready**.

### 3.1 Landing `/`

- 히어로: 한 줄 가치, CTA, 메쉬 그라데이션, 우측 하단 상징 비주얼(덱 카드)
- 모듈 카드 PromptKit / CareerLog / Steam Tracker → 좌우 자동 스크롤(마퀴)
- Steam 위 좌우 섹션: AI Prompt / 개발업무 최신 글 각 최대 4개 (`/p/[id]`, `/work/[id]`). 카드가 아니라 게시판과 같은 리스트 행. 시스템 게시판 비활성·권한 미달이면 빈 상태
- Steam: 가운데 탭 — 누적 시간 순위(1위 2행 + 우측 4장) / 최신 리뷰 목록. 제목 우측 누적시간·더 보기
- 공개 스킬 칩 (`sort_order`). 없으면 해당 섹션 숨김
- 푸터: Next.js · Supabase · Steam API

### 3.1.1 공개 상세 `/p/[id]`

- 대시보드 셸 없음. 랜딩과 같은 공개 헤더
- 제목, 카테고리, 태그, `RichContent` 본문, 복사 버튼
- 좌측 하단 `ArticleReader` 도크: 접힘 시 **본문 크기** 라벨만, 클릭하면 위로 가로 게이지(원본 100%가 가운데, 70–130%). **원래대로**로 초기화. 본문 제목·본문·코드는 `em` 비율로 함께 조절. 반투명 블러. localStorage
- 수정/삭제/공개 토글 없음. Owner면 “대시보드에서 편집” 링크만
- 없거나 `is_public = false`이면 `notFound()`. 목록 6개 밖 공개 글도 URL이면 열림

### 3.1.2 공개 커리어 게시판 `/work`

- 공개 헤더. 제목: 커리어
- 상단 검색: 제목 조건 + 검색어 + 검색/초기화. `총 N건`
- 리스트 행: `No. N | 제목`, 아래 `작성자 | 등록일`, 우측 `post_type`. 조회수 컬럼은 없음
- 정렬: `created_at DESC`. 한도 없음
- Empty: “아직 공개된 글이 없습니다”

### 3.1.3 공개 커리어 상세 `/work/[id]`

- 블로그 레이아웃. 제목, type, 회사/역할/기간, 스킬·태그, `RichContent` 본문
- `/p/[id]`와 같은 본문 크기 도크
- 수정 UI 없음. Owner면 “대시보드에서 편집”
- 없거나 비공개면 `notFound()`

### 3.1.4 범용 게시글 `/b/[slug]/[id]`

- 제목 + `RichContent` 본문. 쓰기 권한이 있으면 아래 수정 폼
- `/p/[id]`와 같은 본문 크기 도크. 시스템 게시판 슬러그는 404

### 3.2 Login `/login`

- Google만
- 에러 쿼리(`?error=`) 시 Alert

### 3.3 PromptKit 목록 `/promptkit`

**헤더:** 제목

**필터:** 제목 검색, 총 건수

**리스트:** `No. N | 제목`, 작성자(관리자), 등록일, 우측 카테고리·공개 여부. 복사는 상세에서

**Empty:** “첫 프롬프트를 저장하세요”

**생성:** `/promptkit` 위 패널. 필드: title, category(텍스트 입력, placeholder `General`), tags(콤마), content(`RichEditor` / CKEditor 5), is_public switch

### 3.4 PromptKit 상세 `/promptkit/[id]`

- 보기 / 편집 토글
- 복사, 공개 토글, 삭제(AlertDialog)
- 없으면 `notFound()`

### 3.5 CareerLog 목록 `/career`

**헤더:** 커리어, 스킬 관리(`/career/skills`)

**필터:** 제목 검색, 총 건수

**리스트:** `No. N | 제목`, 작성자(회사 또는 관리자), 등록일, 우측 type·공개 여부

**Empty:** “참여했던 프로젝트를 글로 남겨 보세요”

**생성/수정 필드:** title, post_type(세그먼트 또는 select), excerpt, content(`RichEditor`), company, role, period_start, period_end(비우면 진행 중), skills(콤마), tags(콤마), is_public

프로젝트 메타 필드는 `post_type = project`일 때 강조. 다른 타입이어도 입력은 허용한다.

### 3.6 CareerLog 상세 `/career/[id]`

- 보기 / 편집 토글
- 공개 토글, 삭제
- 없으면 `notFound()`

### 3.7 CareerLog 스킬 `/career/skills`

- 테이블 또는 카드 목록. `sort_order`로 위아래 (MVP는 숫자 입력으로도 충분)
- 필드: name, category, proficiency, years, summary, is_public
- 이름 중복 시 에러 토스트

### 3.8 Steam 목록 `/steam`

**헤더:** 프로필 아바타·이름, 게임 수, 누적/2주/Deck 시간, 마지막 플레이 게임

**정렬:** 누적 시간 (즐겨찾기 우선), 최근 플레이, 최근 2주

**카드:** header.jpg, name, 누적 시간, 마지막 플레이, 2주·Deck 배지, 리뷰 있음 점, 즐겨찾기 별

**Empty:** Steam 설정 안내 (프로필 공개, env)

**Error:** 프록시 메시지 그대로 보여 주되 시크릿 없음

공개 `/games`도 같은 `SteamLibrary`를 쓴다.

### 3.9 Steam 상세 `/steam/[appid]` · `/games/[appid]`

- 히어로(`library_hero` → header), 이름, Steam 상점 링크
- 누적/2주/마지막 플레이, 플랫폼·Deck 시간, Deck 호환, 업적 진행
- 상점 한 줄 소개, 장르, 개발/퍼블리셔, 출시일, Metacritic, 스크린샷
- 관리자: `StarRating` + `RichEditor` 리뷰, umpc_preset, is_favorite
- 공개: 리뷰 본문 읽기 전용, 본문 크기 도크
- 상점 API 실패 시에도 라이브러리·리뷰는 유지

`ROG Ally / Lossless Scaling ON / 15W TDP / 1080p 60FPS`

## 4. 컴포넌트 인벤토리

### `components/ui` (shadcn/ui)

Button, Input, Textarea, Label, Card, Badge, Switch, `StarRating`, `Skeleton`.

### `components/layout`

- `AppSidebar`
- `UserMenu`
- `ThemeToggle`
- `PublicHeader` / `PublicHeaderNav` (메가메뉴)
- `PublicFooter` (공개 페이지. shadcn `dark` 토큰 배경, 브랜드·모듈 링크·연락)

### `components/board`

- `PostList` — 제목 검색, `총 N건`, `No. N | 제목` / 작성자·등록일 행. 공개 게시판·랜딩 최신글·대시보드 글 목록 공용
- `ArticleReader` — 공개 상세 본문 배율(`--article-font-scale`) + 좌측 하단 접이식 가로 게이지·원래대로
- `PublicPostForm`

### `components/promptkit`

- `PromptCard`
- `PromptForm`
- `RichEditor` / `RichContent` (CKEditor 5)
- `CopyPromptButton`

### `components/career`

- `CareerPostCard`
- `CareerPostForm`
- `CareerSkillChip`
- `CareerSkillForm`
- `PeriodLabel` (`2021.03 – 2023.08` / `2024.01 – 현재`)

### `components/steam`

- `GameCatalog` (상점·플레이 메타)
- `GameReviewForm` (`StarRating` + `RichEditor`)
- `PlaytimeLabel`

## 5. 카피 톤

- 한국어 UI
- 짧은 문장. 대시보드 라벨은 명사 위주
- 에러는 원인과 다음 행동 한 줄 (`Steam 응답이 실패했습니다. 잠시 후 다시 열어 보세요.`)

## 6. 접근성 / 반응형

- 사이드바 접힘 < md
- 아이콘 버튼은 `sr-only` 라벨
- 복사 성공은 toast + 버튼 텍스트 일시 변경

## 7. 하지 않는 UI (MVP)

- 커스텀 차트 대시보드
- 드래그 앤 드롭 프롬프트 보드
- Steam 업적 그리드
- 커리어 댓글 / 커버 이미지 / 타임라인 연도 스크롤
- 다국어 i18n 프레임워크 (카피는 한국어 하드코드)
